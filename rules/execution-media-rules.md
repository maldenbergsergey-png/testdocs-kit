# Supplied test evidence

#### Проверка по материалам пользователя

- Использовать уже предоставленные материалы; запросить только недостающие для конкретных пунктов. Скринкаст должен показывать исходное состояние, действия и результат; скриншот подходит для видимого состояния и оформления.
- Сопоставлять видимое с условиями задачи и подтверждённым ожидаемым результатом. Скриншот итогового экрана не доказывает путь к нему, успешный сетевой запрос или сохранение данных после повторного открытия. Не достраивать невидимые действия и поведение между кадрами; неизвестные сборку, окружение и роль явно отмечать.
- Указывать "Проверено по материалам пользователя", исходный файл и время в видео. Сохранять привязку к строкам по [правилам доказательств](execution-evidence-rules.md). При смешанном прогоне различать источник в каждой строке; не выдавать запись за самостоятельный прогон.
- Статус выбирать по фактически подтверждённому объёму пункта. Непоказанные действия, состояния и платформы остаются `НЕ ПРОВЕРЕНО` или `ЧАСТИЧНО ПРОВЕРЕНО`; неопределённый ожидаемый результат - `ТРЕБУЕТ УТОЧНЕНИЯ`. Не переносить успешный результат видимой части на весь сценарий.
