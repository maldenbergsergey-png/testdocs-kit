# Краткие вводные QA Report

Учебные данные. Значения относятся только к примерам, а не к реальному прогону или настройкам проекта.

| Ситуация | Поле "Окружение" | Поле "Вводные данные" |
| --- | --- | --- |
| iOS, симулятор; часть запрошенного недоступна | DEV | iOS 18; сборка 42; iPhone 16, симулятор, 393×852 pt. Нет данных для проверки лота без цены. |
| Android, физическое устройство; общих ограничений нет | STAGE | Android 15; сборка 87; Pixel 9. |
| Web; точная версия известна | STAGE | Firefox 130. |
| Web; пользователь указал, что всегда использует последнюю версию | PROD | Chrome, последняя версия. |
| Известен только браузер, соглашения о версии нет | DEV | Chrome. |
| Известен стенд; данных о клиенте и общих ограничениях нет | STAGE | Поле пустое. |
| Нестандартный стенд с подтверждённым коротким именем | demo-blue | Chrome 128. Адрес стенда: [Открыть стенд](https://demo-blue.example.test). |

Размер указывается один раз, с единицами симулятора. Разрешение полученного скриншота не добавляется. Отдельные непроверенные пункты и ссылки на требования остаются в комментариях строк. Общий итог и статистика не повторяются во вводных.

При Jira-импорте строка `Окружение: DEV` задаёт категорию стенда. Сведения о клиенте писать отдельной строкой без префикса `Окружение:`, чтобы они остались во вводных. Для ссылки на стенд применять именованную Jira-ссылку по [профилю доставки](../../integrations/profiles/qa-report.md#task-link-and-environment-mapping). Если API не поддерживает запись нужного поля, сообщить об этом отдельно; не выдавать содержимое за сохранённые метаданные.
