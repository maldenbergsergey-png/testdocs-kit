# Компактный checklist без искусственных разделов

Учебное требование: под заголовком опубликованного материала видна дата в формате ДД.ММ.ГГГГ. У черновика без даты блок скрыт. Требования полны, поэтому вопросов нет.

```text
h2. Отображение даты публикации
||Номер||Проверка||Как проверить||Ожидаемый результат||Фактический результат||Комментарий||Статус||
|1.|Дата опубликованного материала|Открыть опубликованный материал с известной датой|Под заголовком отображается дата публикации в формате ДД.ММ.ГГГГ| | | |
|2.|Отсутствие даты у черновика|Открыть черновик без даты публикации|Блок даты публикации не отображается| | | |
```
