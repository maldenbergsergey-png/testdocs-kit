# Постоянное покрытие менять не требуется

Изменения постоянного тестового покрытия:

- Создание: не требуется.
- Актуализация: не требуется.
- Сделать неактуальными: не требуется.

`DEMO-T100` уже проверяет изменяемый пользовательский сценарий и содержит правильный ожидаемый результат. Дополнительные task-specific проверки отражены только в чек-листе.
