# Только task checklist

Запрос: `Подготовь чек-лист для изменения сортировки объектов.`

Учебное требование: GET /api/items без sort возвращает объекты по возрастанию цены; sort=price_desc - по убыванию. Повторный запрос неизменённых данных сохраняет порядок. Порядок при одинаковой цене не определён.

```text
h2. Сортировка списка
||Номер||Проверка||Как проверить||Ожидаемый результат||Фактический результат||Комментарий||Статус||
|1.|Сортировка по умолчанию|Отправить GET /api/items без sort|Объекты идут по возрастанию цены| | | |
|2.|Сортировка по убыванию цены|Отправить GET /api/items?sort=price_desc|Объекты идут по убыванию цены| | | |
|3.|Стабильность повторного запроса|Повторить GET /api/items на неизменённых данных|Порядок объектов в ответах одинаков| | | |
h2. Требует уточнения
||Номер||Вопрос||Текущее наблюдение||Статус||
|1.|Правило tie-breaker для одинаковых значений|Источник не определяет дополнительный критерий сортировки|{color:#bf6700}*ТРЕБУЕТ УТОЧНЕНИЯ*{color}|
```

Раздел `Требует уточнения` появился здесь только потому, что в исходном контексте действительно не определён tie-breaker. При полном требовании checklist завершился бы после исполнимой таблицы.
