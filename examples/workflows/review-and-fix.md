# Review и исправленная proposal-версия

Review показывает общий статус, для каждого замечания — место, правило, проблему, важность и рекомендацию. При content findings ниже сразу приводится полный исправленный Test Case. Статус proposal: `НЕ ПРИМЕНЕНО`; запись возможна только после отдельного явного запроса и проверки актуальности baseline.
