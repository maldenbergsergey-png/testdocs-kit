# Create, update и retire proposal

- `Создать`: постоянный сценарий с новым самостоятельным outcome; существующее покрытие области подтверждённо полное.
- `Актуализировать DEMO-T42`: текущий expected result устарел; вывод содержит `ИЗМЕНИТЬ` и полный final proposal.
- `Сделать неактуальным DEMO-T41`: описанный flow удалён; рекомендуется сменить организационный статус после review.

Ни одно решение само по себе не выполняет внешнюю запись или удаление.
