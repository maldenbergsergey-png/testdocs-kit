# Пример переиспользуемого регрессионного тест-кейса

> Демонстрационный обезличенный пример. Требование `R-EXAMPLE-17` задаёт описанное вымышленное поведение и отмечает создание объекта как критичный пользовательский путь.

**Название:** Создание объекта. Запрет сохранения без названия

**Цель:** Проверить невозможность создать объект без значения обязательного поля «Название».

**Предусловия:**

- Пользователь авторизован.
- Открыта форма создания объекта.

**Путь:** `/objects/new`

| № | Шаг | Тестовые данные | Ожидаемый результат |
| --- | --- | --- | --- |
| 1 | Оставить поле «Название» пустым. | Пустое значение | Поле «Название» не содержит введённого значения. |
| 2 | Нажать кнопку «Сохранить». | Не требуются | Для поля «Название» отображается признак обязательности, форма остаётся открытой, объект не добавляется в список. |

**Постусловия:** Не требуются; объект не создаётся.

**Теги:** `block`, `web`

**Статус:** `Готов к ревью`

**Приоритет:** `High`
