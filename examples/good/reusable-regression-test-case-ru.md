# Пример переиспользуемого регрессионного тест-кейса

> Демонстрационный обезличенный пример. Требование `R-EXAMPLE-17` задаёт описанное вымышленное поведение и отмечает создание объекта как критичный пользовательский путь.

**Название:** WEB. Создание объекта. Запрет сохранения без обязательного названия

**Цель:** Проверка невозможности создать объект без значения обязательного поля «Название».

**Теги:** `block`, `web`

**Предлагаемый статус:** `Готов к ревью`

**Приоритет:** `High` — ошибка допускает некорректные данные в критичном сценарии создания.

**Путь:** `/objects/new`

**Предусловия:**

- Пользователь авторизован.
- Открыта форма создания объекта.

**Тестовые данные:** Поле «Название» не содержит символов.

| № | Действие | Ожидаемый результат |
| --- | --- | --- |
| 1 | Оставить поле «Название» пустым. | Поле «Название» не содержит введённого значения. |
| 2 | Нажать кнопку «Сохранить». | Для поля «Название» отображается признак обязательности, форма остаётся открытой, объект не добавляется в список. |

**Примечания для регрессии:** Кейс проверяет один стабильный негативный сценарий, не зависит от порядка запуска и не фиксирует точный текст сообщения, поскольку он не задан демонстрационным требованием.

**Постусловия:** Не требуются; объект не создаётся.
