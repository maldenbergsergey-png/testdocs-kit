# Создание сущности в админке с проверкой в API

> Обезличенный демонстрационный пример. Названия, пути и контракт ниже вымышлены и служат только для объяснения структуры. В реальном кейсе их берут из материалов текущего проекта.

Условия примера:

- Тестовый профиль среды задаёт адрес админки, соответствующий API base URL и настроенную авторизацию для чтения API. Тестировщику разрешено создавать материалы и читать их через API.
- В разделе "Категории" есть выбранная для теста категория. Её название и ID видны в карточке. Поле "Категория" в форме материала позволяет выбрать её по этим данным.
- Для создания материала нужны только название, категория и статус "Опубликован". После сохранения открывается карточка с ID и сохранёнными значениями. ID материала и категории являются строками.
- Контракт требует появления материала сразу после сохранения в трёх методах ниже. Каждый возвращает HTTP `200`. Два списка возвращают массив `items` с полями `id` и `title`; метод карточки возвращает объект с `id`, `title`, `status` и `categoryId`. Статусу "Опубликован" соответствует `published`. Фильтр `title` ищет точное название.
- Созданный материал можно использовать в зависимых кейсах. После их завершения создавший его тестировщик удаляет материал через доступное в карточке действие "Удалить" с подтверждением; существующую категорию сохраняет.

Скриншот не приложен: пример подготовлен по текстовому контракту, доступ к админке и готовый снимок не предоставлены. Реальное выполнение не проводилось.

**Название:** Админка. Материалы. Создание опубликованного материала в категории

**Цель:** Проверить создание материала со связью с категорией и возврат его данных в связанных API-методах.

**Предусловия:**

- Выбран разрешённый тестовый профиль среды с адресом админки, соответствующим API base URL и настроенной авторизацией для чтения API.
- Тестировщик вошёл в админку с правом создания материалов.
- Выбрана существующая тестовая категория в разделе "Категории".
- API-клиент использует тот же профиль среды.

**Путь:** `/admin/materials/`

| № | Шаг | Тестовые данные | Ожидаемый результат |
| --- | --- | --- | --- |
| 1 | Создание и настройка сущности: открыть карточку выбранной категории в разделе "Категории" и записать её название и ID для следующих шагов. | Выбранная тестовая категория | В карточке отображаются название категории и её `categoryId`. |
| 2 | Перейти в раздел "Материалы". |  | Открывается список материалов. |
| 3 | Нажать "Создать материал". |  | Открывается форма создания материала. |
| 4 | Ввести название в поле "Название". | `Материал [уникальный идентификатор запуска]`, далее `materialTitle` | Поле содержит введённое название. |
| 5 | В поле "Категория" выбрать категорию по названию и ID из шага 1. | • Название категории из шага 1<br>• `categoryId` из шага 1 | В поле выбрана указанная категория. |
| 6 | Выбрать значение в поле "Статус". | "Опубликован" | В поле выбран статус "Опубликован". |
| 7 | Нажать "Сохранить". |  | • Открывается карточка созданного материала с его `materialId`<br>• Название равно `materialTitle`<br>• Выбрана категория с `categoryId` из шага 1<br>• Статус равен "Опубликован" |
| 8 | Записать ID из карточки материала для API-проверок и зависимых кейсов. |  | Сохранён `materialId` именно созданного материала. |
| 9 | Проверка в API: выполнить `GET /api/materials` с фильтрами по категории и названию. | • API base URL из выбранного профиля среды<br>• Query `categoryId`: значение из шага 1<br>• Query `title`: `materialTitle` из шага 4 | • HTTP `200`<br>• В `items` присутствует объект с `id`, равным `materialId` из шага 8<br>• Его `title` равен `materialTitle` |
| 10 | Выполнить `GET /api/materials/[materialId]`. | • API base URL из того же профиля среды<br>• Параметр пути `materialId`: значение из шага 8 | • HTTP `200`<br>• `id` равен `materialId`<br>• `title` равен `materialTitle`<br>• `status` равен `published`<br>• `categoryId` равен ID выбранной категории из шага 1 |
| 11 | Выполнить `GET /api/categories/[categoryId]/materials`. | • API base URL из того же профиля среды<br>• Параметр пути `categoryId`: значение из шага 1 | • HTTP `200`<br>• В `items` присутствует объект с `id`, равным `materialId`<br>• Его `title` равен `materialTitle` |

**Постусловия:** передать `materialId`, `materialTitle` и выбранный профиль среды зависимым кейсам. После их завершения создавший материал тестировщик открывает его карточку в "Материалах", нажимает "Удалить" и подтверждает удаление. Если зависимых кейсов нет, удалить материал после API-проверок. Существующую категорию сохранить.
