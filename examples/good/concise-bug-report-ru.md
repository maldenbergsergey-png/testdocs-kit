# Краткий баг-репорт

Учебные данные: тестировщик наблюдал сохранение имени в web-профиле; требование из чата задаёт закрытие формы после сохранения. Причина дефекта неизвестна. Пример - черновик, запись в трекер не выполнялась.

**Название:** FE. Профиль - форма остаётся открытой после сохранения имени

**Предусловие:** Пользователь авторизован, открыта форма редактирования профиля /profile/edit.

**Шаги воспроизведения:**

1. Ввожу в поле "Имя" значение "Анна".
2. Нажимаю "Сохранить".

**Фактический результат:** Имя сохранилось, форма осталась открытой.

**Ожидаемый результат:** Имя сохраняется, форма закрывается.

**Окружение:** STAGE, Chrome 128.

При создании в Jira каждый блок переносится в своё поле, если оно доступно в полной схеме выбранного типа бага: "Окружение", "Шаги воспроизведения", "Фактический результат", "Ожидаемый результат". В "Описание" остаются предусловие и материалы. Если отдельного поля нет, только этот блок добавляется в "Описание" под своим заголовком. Названия и ID полей берутся из текущей Jira.
