# Пример простого тест-кейса

> Демонстрационный обезличенный пример. Вымышленное требование `R-EXAMPLE-1` определяет создание объекта с обязательным названием как критичный пользовательский путь.

**Название:** Создание объекта. Сохранение с заполненным названием

**Цель:** Проверить создание объекта при заполнении обязательного поля "Название".

**Предусловия:**

- Пользователь авторизован.
- Открыта форма создания объекта.

**Путь:** `/items/new`

| № | Шаг | Тестовые данные | Ожидаемый результат |
| --- | --- | --- | --- |
| 1 | Ввести название и нажать "Сохранить". | Название: Тестовый объект [уникальный идентификатор запуска] | • Форма закрывается<br>• В списке отображается объект с введённым названием |

**Постусловия:** Удалить созданный объект.

**Теги:** `block`, `web`

**Статус:** `Готов к ревью`

**Приоритет:** `High`
