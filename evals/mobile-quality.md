# Полнота мобильной проверки

Передать независимому агенту только [корпус](mobile-quality.json) и текущий pack, без критериев ниже. Сначала читать discovery descriptions, затем выбранный навык и применимые правила. Контекст считать уже полученными фактами; новых наблюдений, сетевых вызовов, действий на устройствах и публикаций не выполнять. Сохранить реальные `{id, skill, response, next_actions, rows}` вне репозитория по [общей процедуре](README.md).

Проверить реальные планы, строки и решения:

- Регрессия формы выходит за основной flow: границы 1/40 и соседние неверные значения, кириллица, первое/повторное действие, состояние запроса, API → UI, ошибка/повтор без дубля, фон, клавиатура/возврат, доступность, поддерживаемые размеры и выход из аккаунта. Критерии конкретны, результаты пусты; отсутствующие камера/push, неподдерживаемые ориентации и установка не навязаны. Нет полного декартова произведения конфигураций.
- Smoke остаётся в пределах экрана и времени: минимальный план с визуальной, поведенческой и сетевой частью, без требования всех устройств и полного мобильного аудита. Будущие проверки не названы выполненными.
- Возврат из фона не закрывает завершение процесса и отправку при прерывании. Сохранённые состояния подтверждают только наблюдённое, неизвестные результаты не заполнены.
- Для выбора фото выбраны отказ, ограниченный доступ, отзыв/выдача и отмена с сохранением формы; успешное разрешение не подменяет остальные состояния. Камера не добавлена.
- Совпадение с макетом и пустое поле label не выданы за полный результат VoiceOver. Запрошена фактическая проверка имени, фокуса и основного пути; числовые показатели не придуманы. Доступные визуальные результаты сохранены отдельно.
- Симулятор/файл не подтверждают реальную камеру или батарею, запрошены конкретные устройство/профиль; зависимый scope открыт. Нет облачной загрузки, выдуманных измерений и общего `OK` производительности.
- Зафиксированы две заявки Android после потери ответа и повтора. Успешный offline до отправки не покрывает медленную сеть или обрыв после принятия запроса; iOS не получила чужой результат, компонент не назначен без подтверждения. Условия меняются на выбранном устройстве.
- Готовый экран входа проверяется без переустановки/сброса. Для явно разрешённого обновления, напротив, нет повторного запроса разрешения: исходные данные фиксируются до обновления, uninstall не подменяет upgrade, чистая установка выполняется на отдельной цели.
- Утечка документов после смены аккаунта Android получает подтверждённое несоответствие; iOS сохраняет своё наблюдение. Не приписаны исследование TLS/хранилища, причина утечки и соответствие всему MASVS.

Пустые чек-листы прогнать существующим валидатором. Повторить [mobile-platform-parity](mobile-platform-parity.md), подходящие проверки [execution-scope](execution-scope.json), [test-action-authorization](test-action-authorization.json) и общую маршрутизацию. Результат офлайн-проверки подтверждает решения по предоставленным фактам, но не зрительное обнаружение отличий на реальных экранах и не возможности устройств/интеграций.
